# 🚗 Premium Auto Detailing Template

A high-performance, modern, and fully responsive website template designed specifically for premium auto detailing services. Showcases ceramic coating, paint correction, interior restoration, and other obsessive car care services. Built with industry-standard web tech and smooth animations to provide an ultra-premium user experience.

Live Demo: [https://kanishkam2406.github.io/Car-Detailing-template-/](https://kanishkam2406.github.io/Car-Detailing-template-/) (or your deployed Vercel/Netlify link)

---

## ✨ Features

- 🎨 **Premium Aesthetics:** Dark mode interface utilizing modern glassmorphism, responsive grids, and clean typography.
- ⚡ **High Performance & Developer-Friendly:** Built with **React 18**, **TypeScript**, and **Vite** for rapid hot-reloads and optimized bundler output.
- 💫 **Sophisticated Animations:** GSAP (GreenSock Animation Platform) integrated animations and page transitions.
- 🎭 **Smooth Scrolling:** Utilizes Lenis smooth-scroll libraries and parallax background modules.
- 📸 **Before/After Interactive Slider:** Let potential clients slide to see the result of your paint correction and interior detailing.
- 🛠️ **Pre-built Sections:**
  - **Dynamic Hero Section:** Engaging intro with smooth animation.
  - **Services / Pricing Grid:** Segmented detailing packages with hover effects.
  - **Interactive Process Roadmap:** Step-by-step description of detailing stages.
  - **Portfolio Gallery:** Modern layout for displaying detailed vehicles.
  - **Testimonials Showcase:** Highlighting reviews from satisfied customers.
  - **Interactive Leaflet/Google Map Section:** Custom styled map for business locations.
  - **Call to Action (CTA) Form:** High-conversion contact forms for bookings.

## 🚀 Getting Started

Follow these steps to set up the project locally:

### Prerequisites

You will need either `Node.js` (v18+) or `Bun` installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kanishkam2406/Car-Detailing-template-.git
   cd Car-Detailing-template-
   ```

2. **Install dependencies:**
   Using npm:
   ```bash
   npm install
   ```
   Or using Bun:
   ```bash
   bun install
   ```

3. **Start the development server:**
   Using npm:
   ```bash
   npm run dev
   ```
   Or using Bun:
   ```bash
   bun dev
   ```

4. **Build for production:**
   Using npm:
   ```bash
   npm run build
   ```
   Or using Bun:
   ```bash
   bun run build
   ```

## 📁 Project Structure

```
├── public/              # Static assets (images, icons)
├── src/
│   ├── assets/          # Project-specific local assets
│   ├── components/      # Reusable React components
│   │   ├── sections/    # Individual sections of the page (Hero, Services, CTA)
│   │   └── ui/          # Low-level UI primitives (button, input, etc.)
│   ├── hooks/           # Custom React hooks
│   ├── lib/             # Helper utilities (cn, etc.)
│   ├── pages/           # Main page views (Index, NotFound)
│   ├── App.tsx          # App routing and layout
│   └── main.tsx         # Entry point script
├── index.html           # Main HTML document
├── tailwind.config.ts   # Tailwind configuration
└── vite.config.ts       # Vite build configuration
```
